PROJECT DOCUMENTATION - Data Analysis using NumPy and pandas

PROJECT OVERVIEW
This project demonstrates core data manipulation techniques using Python's NumPy and Pandas libraries.It includes array mathematical operations, dataset slicing, custom indexing, data filtering, and aggregation.

TOOLS USED
1.NumPy
2.Pandas
3.Jupyter Notebook

STEPS FOLLOWED
*NumPy Array Operations
1.Created a 1D array temperatures_w1 and inspected its shape, data type and size.
2.Converted Celsius to Fahrenheit and found the minimum, maximum and mean.
3.Sliced the first three days, the weekend and the middle three days.
4.Created a 2D array temperatures and extracted each week and the weekends' temperature.
*Pandas 
1.Created the Series marks with custom indices.
2.Accessed values using integer position, loc, iloc and a boolean mask.
3.Modified the Rank1 mark to 100, removed Rank5 and computed CGPA.
4.Created the DataFrame transactions.
5.Explored data using head, tail, shape, columns and dtypes
6.Selected columns using loc and iloc, and filtered rows with conditions.
7.Counted categories and found unique regions using groupby and drop_duplicates.
8.Grouped by Region to find the mean amount.
9.Updated an amount, added and deleted a Discount column, and removed a row using drop.

KEY INSIGHTS
1.Week 1 temperatures ranged from 20.8 °C to 26.1 °C, with a mean of about 23.54 °C.
2.Electronics is the most frequent product category (4 of 10 transactions).
3.The East region has the highest mean transaction amount (375.0) and the West region the lowest (190.0).
